# API REST EMPLEADOS 

Aqui se implementa una API REST en Kotlin MultiPlatform, permite gestionar la entidad empleados. 

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio.
2. Asegúrate de tener Kotlin y Gradle configurados.
3. Ejecuta la función `main()` del archivo principal:
   bash
   ./gradlew run

La API esta disponible en http://localhost:8080
